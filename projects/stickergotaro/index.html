Why It's Built This Way

为什么这么做

磁贴成长纪最早只是给孩子做的一个"代币制"小程序：完成任务，赚磁贴，换心愿。 做着做着我发现，最难的不是让孩子完成任务，而是让习惯真的长出来。

安卓版是一次更诚实的重做。我把每个"功能"重新想了一遍， 最后它们都指向同一件事：把任务按人归集，把奖励交给命运，让每个操作都有魔法感。 因为一个习惯能否长出来，取决于孩子做完之后还想不想再做一次。

👨‍👩‍👧

任务按人归集 —— 不是清单，是关系

爷爷是 ISTP，话少手巧，他的任务叫"一起修好一件小玩具"；奶奶是 INFP，温柔有想象力，她的任务叫"一起画一幅画"。任务不再是一张冷冰冰的待办表，而是每个人用自己的方式参与小满的成长。

MBTI 不是标签，是"这个人能给孩子什么"的说明书。一家人各用自己的长处陪孩子，而不是只有妈妈一个人念清单。
🎰

每日扭蛋 —— 把命运交给随机

每天一次，蛋从扭蛋机里掉出来：掉落、摇晃、裂开、发光。60% 是普通蛋，5% 是彩虹蛋。因为不知道会抽到什么，所以每天都想再扭一次。

习惯养成需要确定性，也需要一点点惊喜。不确定的奖励反而比确定的更让人期待——孩子不只是完成任务，是在玩一个每天开奖的小游戏。
🌈

心情转换器 —— 置身其中不陷进去

坏情绪是一只灰色的小怪兽。孩子选一个情绪，深呼吸，看着它从灰色慢慢变成彩色。坏心情不用被消灭，只需要被转化。

这个功能里藏着我自己的生活哲学：情绪来了，承认它、看着它，别被它带走。"可能既没那么糟，也没那么好。"
🏅

勋章收集册 —— 从做事到成为

十枚勋章，四页收集册：传说、勇气、智慧、见证。未解锁的是一格虚线框，里面画着"？"和进度。点开一枚勋章，会看到它推荐的任务。

勋章不是墙上的荣誉，是一张行动清单：想成为勇敢的人，就去做那些关于勇气的事。从"我完成了"到"我是这样的人"。
👾

小怪兽精灵 —— 让每个操作有魔法感

每个任务旁边住着一只 Q 版小怪兽，会呼吸、会打瞌睡。完成任务时它跳起来庆祝；情绪转化、扭蛋开箱、图片展开，每一处都有动画、声音和震动。

孩子不需要看懂机制，只要感觉"这很好玩"。魔法感是习惯最诚实的入口——觉得好玩，才会再来。
☁️

家人档案 + 云同步 —— 全家参与，不只在手机里

每个家人有一份完整档案：MBTI、性格、兴趣、家庭角色、育儿建议，可以一键导出分享。记录、照片、任务、家人档案都能同步到云端。

成长不该只发生在一台手机上。全家人的参与方式值得被认真设计，也值得被保存下来、带得走。

Design Highlights

设计亮点

🧲

双轨激励制

磁贴管日常小奖励，许愿星管低频大梦想。高频即时反馈 + 低频延迟满足分离，孩子不用艰难地攒几十个磁贴去换一个大愿望。

Token Economy Dual-Track
🎰

加权随机扭蛋

每日一次，60% 普通蛋 / 25% 银蛋 / 10% 金蛋 / 5% 彩虹蛋。掉落 → 摇晃 → 裂开 → 光效，一套完整的开蛋仪式。

Variable Reward Lottie
👾

任务小怪兽精灵

吃饭、洗澡、收纳、守时、作息，每个任务有一只专属小怪兽，idle 时轻轻呼吸，完成时 burst 庆祝，做完就"睡着了"。

Mascot Lottie
🏅

勋章 → 任务闭环

点开未解锁勋章，看到它推荐的具体任务，一键加进首页。勋章从"展示荣誉"变成"通往品质的行动清单"。

Collection Book Actionable
🌈

心情转换魔法

灰色小怪兽在孩子的深呼吸中慢慢变成彩色，配上升调音效与震动。情绪管理不是讲道理，是一场看得见的转化。

Emotion Magic
🎵

多模态反馈

每次操作都有动画 + 合成音效 + 震动三层回应。声音用 WebAudio 实时合成（金币音、礼炮音、风铃音），无需音频文件。

WebAudio Haptics
